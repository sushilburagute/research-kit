# Roadmap

## P0 - research the author can use

- Establish the reader, question, tentative angle, scope, and capability limits.
- Investigate questions through source reading and iterative follow-up.
- Track claims, sources, upstream origins, dates, versions, and limitations.
- Search for counterevidence and distinguish unresolved from contradicted claims.
- Deliver an author-friendly brief, evidence ledger, and honest completion report.
- Preserve the author's narrative, notes, personal experience, and decisions.

This PR supplies the skill instructions, references, templates, structural checks, and behavioral evaluation scenarios. Live research performance still needs evaluation on real articles.

## P1 - develop and finish an article

- Follow changing narrative questions across sessions.
- Audit an author's draft against its evidence.
- Apply an editable writing profile and offer targeted editorial suggestions.
- Validate evidence files with a structured schema when repeated use justifies it.
- Add one React/MDX repo adapter and use the site's existing build checks.
- Test the skill through an existing Obsidian agent integration.

## P2 - richer production and managed workflows

- Research maps, diagrams, interactive examples, and simulations.
- Talk structure, speaker notes, demos, and rehearsal material.
- Newsletter and social drafts derived from approved content.
- Optional research backends and parallel execution.
- A custom Obsidian interface or standalone app when actual usage supports it.
- Managed publishing, scheduling, hosting, collaboration, and team services.

Choose subsequent work from observed failures on real articles. Compare against a normal agent prompt on evidence accuracy, missing counterarguments, corrections, and research the author had to repeat. Treat model scores as editorial signals, not factual accuracy certificates.
